 B. YÊU CẦU CHUNG
---------------------------------------------------------------------
 R1  Java IO, OOP, Collections + Generics ......... Có (SlangWord bất biến, HashMap/List/Optional, generic LatestTask<T>...)
 R2  Giao diện Swing, có thanh điều hướng ......... Có (sidebar trái, 10 chức năng)
 R3  Load file -> cấu trúc dữ liệu tối ưu ......... Có: List<SlangWord> + Map<String, IntList> (khóa IN HOA) + inverted index
 R4  Lưu index ra file ............................ Có: data/slang.index.bin (nhị phân tự định nghĩa, hợp lệ khi kích thước + CRC32
                                                    của slang.current.txt khớp; hỏng/lệch -> tự build lại, không crash). Mở 7.641 từ ≈ 26 ms
                                                    (từ cache) / 69 ms (build lại).
 R5  Lưu danh sách sau add/edit/delete ............ Có: ghi slang.current.txt trước (file tạm + move), rồi mới đổi RAM
 R6  Dùng Git, ảnh chụp commit .................... Có: docs/commits/ ([ĐIỀN SỐ COMMIT])
 R7  Không chỉ dùng List .......................... Có: Map + inverted index

 Xử lý dữ liệu lỗi (yêu cầu GV): header, dòng "mồ côi" (nghĩa bị xuống dòng), khoảng trắng thừa, lỗi mã hóa, dòng trùng, slang chứa '|'
 đều được xử lý; SlangFileReader phòng thủ (dòng hỏng bị bỏ + log, không crash). File dữ liệu/index/history thiếu hoặc hỏng không làm
 ứng dụng crash (hộp thoại thân thiện hoặc tự phục hồi). History ở file riêng. Chạy hoàn toàn offline.
